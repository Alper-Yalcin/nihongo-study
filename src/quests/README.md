# quests

Bu klasör `quests` bölümüne ait tüm kodu içerir.
Diğer bölümlerden bağımsız olarak geliştirilir.

## Önerilen yapı

pages/        → Sayfalar (route component'ları)
components/   → Bu bölüme özel component'lar
hooks/        → Bu bölüme özel hook'lar
data/         → Statik veri / içerik
types.ts      → Tip tanımları
